## ✨ Features

Aathma isn't just a player; it's an experience.

| Feature | Description | Status |
| :--- | :--- | :---: |
| **Immersive UI** | A beautiful, modern interface with mood-based themes, particle effects, and cinematic modes. | ✅ |
| **10-Band EQ** | Professional-grade equalizer with presets to fine-tune your sound, plus reverb and pitch/tempo controls. | ✅ |
| **8D Surround Audio** | Experience true spatial audio with binaural rotation on any pair of headphones. | ✅ |
| **Live Visualizers** | 5 real-time, FFT-based visualizer modes (Bars, Wave, Circle, Scope) that dance to your music. | ✅ |
| **Synced Lyrics** | Automatic support for embedded lyrics and `.lrc` files, with perfectly timed highlighting. | ✅ |
| **Generative Art** | Don't have album art? Create your own beautiful, animated gradients and save them to the track. | ✅ |
| **Privacy First** | 100% offline. No accounts, no tracking, no data collection. Your library is yours alone. | ✅ |
| **Portable** | No installation needed. Just download, run, and play. Take your music and player anywhere. | ✅ |

## 🚀 Getting Started

Getting started with Aathma is as simple as it gets.

1.  **Download:** Head over to the [**Releases Page**](https://github.com/AatmaPlayer/Aathma/releases/latest).
2.  **Get the right version:**
    *   For **Windows**, download the `.exe` file.
    *   For **macOS**, download the `.dmg` file.
    *   For **Linux**, the `.AppImage` will be available soon.
3.  **Run:** Double-click the downloaded file. No installation required!
4.  **Enjoy:** Drag-and-drop a music file or folder, and feel the vibe.
